# COURTSIDE Prototype Plan

**Goal:** 为手机场边记分与手机 / 平板 / 桌面赛后分析，提供可评审的浅色和深色原型。

**Architecture:** 独立静态 HTML、CSS、JavaScript；与生产 app、数据库和 API 分离。统一虚构比赛驱动列表、分析图表与记分结果。

**Tech Stack:** 原生 HTML / CSS / JavaScript、SVG 图表、Python 静态服务、Playwright 浏览器检查。

## 制作顺序

- [x] 建立 `index.html` 与 `styles.css`：语义主题变量、桌面侧栏、移动底栏、字号与间距。
- [x] 建立 `data.js`：可复现虚构比赛、ELO、战绩、搭档与交锋统计。
- [x] 建立 `app.js`：总览、球员列表与档案、记分流程，主题和身份选择。
- [x] 完成 `DESIGN.md`：主题、响应式、状态、现有代码映射、后续设计范围。
- [x] 浏览器检查：360 / 390 / 768 / 1024 / 1440px，所有页面与两套主题；检查横向溢出、交互、弹层 Escape 关闭和 JavaScript errors。
- [x] 截图检查桌面分析、手机分析与记分，按检查结果调整。
